# Mac Converter (macOS 백그라운드 파일 변환/가공 유틸리티)

Finder에서 파일을 드래그하는 도중 단축키를 눌러 마우스 커서 위치에 나타나는 메뉴에서 마우스 버튼을 놓기만 하면(Drop/Release) 백그라운드에서 즉시 변환/가공이 시작되는 초경량 유틸리티입니다.

---

## 🚀 빠른 시작 및 실행

현재 `MacConverter.app`이 빌드되어 백그라운드(메뉴바)에서 실행 중입니다.

### 실행 방법
```bash
open MacConverter.app
```
* **종료 방법**: 메뉴바 우측 상단의 `Mac Converter` 아이콘(회전 화살표 원형 아이콘)을 클릭하고 **종료 (Quit)**를 누르거나, 터미널에서 `killall MacConverter`를 입력합니다.

---

## ⚙️ 필수 권한 설정 (최초 1회)

마우스 드래그 상태와 글로벌 단축키를 감지하려면 **손쉬운 사용(Accessibility)** 권한이 필요합니다:

1. **[시스템 설정] ➔ [개인정보 보호 및 보안] ➔ [손쉬운 사용 (Accessibility)]**으로 이동합니다.
2. 목록에서 **MacConverter**를 찾아 스위치를 **켬(허용)**으로 설정합니다.
   *(메뉴바 아이콘 클릭 ➔ "손쉬운 사용 권한 설정 열기"를 누르면 해당 설정 페이지가 바로 열립니다.)*

## 🎮 사용 방법 (제스처 가이드)

1. **Finder**에서 변환하거나 가공할 파일(단일 또는 다중)을 마우스 좌클릭한 상태로 **드래그(Drag & Hold)**합니다.
2. 마우스 버튼을 누른 채로 아래의 **단축키**를 누릅니다:
   - **`⌥ (Option)` 키** 또는 **`A` 키**: **형식 변환 (Format Conversion)**
   - **`⌃ (Control)` 키** 또는 **`B` 키**: **파일 가공 (File Processing)**
3. 마우스 포인터 중심에 **원형 방사형 다이얼 메뉴(Radial Pie Menu)**가 즉시 나타납니다.
   - 마우스 커서가 원의 정중앙에 위치하며, 원하는 부채꼴 섹터 방향으로 마우스를 살짝 밀면 해당 섹터가 활성화(초록색 하이라이트)됩니다.
4. 원하는 항목 위에서 **마우스 버튼을 놓으면(Drop/Release)** 해당 작업이 백그라운드에서 즉시 실행됩니다!
   - *취소하고 싶을 때는*: 단축키를 먼저 떼거나(Key Up), 중앙 원(취소 영역) 또는 바깥 영역에서 마우스를 놓으면 아무 작업 없이 취소됩니다.

## 📋 파일별 지원 기능

### 1. [단축키 A / Option] 형식 변환 (Format Conversion)
* **단일 PDF 선택 시** ➔ **`PNG`**: 각 페이지별 300 DPI 초고해상도 분할 추출 (**`[파일명]_PNG` 전용 폴더 자동 생성**)
* **다중 PNG/이미지 선택 시** ➔ **`PDF`**: 파일명/생성일 순 정렬 병합
* **Word (DOCX, DOC)** ➔ **`PDF`**: LibreOffice Headless 엔진을 통해 Word 프로그램 실행 없이 **100% 무음으로 표, 글꼴, 마진, 다단 레이아웃을 원본 그대로 완벽 변환**
* **PowerPoint (PPTX, PPT)** ➔ **`PDF`**: PowerPoint 프로그램 실행 없이 **슬라이드 도형, 디자인, 글꼴을 100% 유지하며 0.5초 무음 변환**
* **다중 PDF 선택 시** ➔ **`PDF 병합`**: 선택된 모든 PDF를 하나의 문서로 결합

### 2. [단축키 B / Control] 파일 가공 (File Processing)
* **이미지 (PNG, JPG, HEIC 등) 선택 시**:
  - **`누끼 따기`**: macOS 내장 Apple Vision 프레임워크 기반 배경 투명 분리 PNG 생성 (`_nobg.png`)
  - **`Crop`**: 화면 중앙에 네이티브 크롭 창 호출 (원하는 영역만 자르고 저장)
  - **`용량 최적화`**: 화질 저하 없는 스마트 압축 (40~70% 용량 다이어트)
* **동영상 (MOV, MP4 등) 선택 시**:
  - **`음원 추출`**: 비디오 제거 M4A/MP3 고품질 오디오 추출
  - **`GIF`**: **동영상 실시간 미리보기 및 재생 바**를 통해 원하는 **시작~종료 구간(초 단위), FPS, 해상도를 직접 조절**하여 고품질 GIF 생성
  - **`ZIP 압축`**: 백그라운드 압축
* **임의의 파일 / 폴더 선택 시**:
  - **`ZIP 압축`**: macOS 네이티브 `ditto` 무음 백그라운드 압축

## ⚡ 실시간 작업 로딩률(Progress) 시스템

* **화면 우상단 플로팅 캡슐 HUD (Dynamic Island style)**: 작업 시작 시 화면 우상단에 세련된 반투명 캡슐이 나타나며 **작업명 + 실시간 프로그레스 바 + 진행률(%)**이 표시됩니다.
* **100% 완료 시**: `✓ 완료` 체크마크 표시 후 1.5초 뒤 부드럽게 페이드아웃 소멸됩니다.
* **메뉴바 인디케이터**: 대용량 비디오 인코딩 중에도 메뉴바 아이콘에서 실시간 `%` 및 미니 링으로 진행 상태를 상시 확인할 수 있습니다.
* **알림 센터**: 작업이 완료되면 동일 폴더에 파일이 생성되며 macOS 배너 알림이 도착합니다. (알림 클릭 시 Finder에서 결과물 자동 선택)
